# Proyecto 1 - Python Fundamentals

Aplicación web desarrollada con **Python** y **Streamlit** como parte del Proyecto 1 del curso **Python Fundamentals** del Instituto DMC.

## Descripción

La aplicación reúne cuatro ejercicios prácticos desarrollados durante el curso:

- 💰 Flujo de caja
- 📦 Registro de productos
- 💳 Cálculo de préstamos mediante funciones externas
- 👨‍💼 CRUD de empleados

## Tecnologías utilizadas

- Python
- Streamlit
- Pandas
- NumPy
- Git
- GitHub
